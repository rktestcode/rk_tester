# RK3576 Unified Hardware Test Platform (rk_tester)

专为 Rockchip RK3576 4路千兆网卡开发板打造的**一站式全功能终端测试工具**（全 ASCII/英文界面，彻底杜绝任何终端乱码与方块字问题）。集成四路网卡静态 IP 自动配置与链路监控、四路网口高频互 Ping 丢包监测（EMC/ESD/EFT抗扰度测试）、RS232/RS485 两两对接持续单向数据传输测试、4路 USB 存储设备并发读写校验压测，以及 CPU/GPU/NPU 全负荷硬件烤机于一体。

---

## 一、4 路独立网口 Ping 丢包监测（EMC 抗扰度测试）

### 1. 什么是 4-LAN Ping & Loss Monitor？
在工业控制与 EMC 实验室环境（静电放电 ESD、电快速瞬变脉冲群 EFT、浪涌测试）中，需要实时检验设备在受到强电磁干扰时，4 个千兆网口是否会出现瞬时丢包（Glitch）或网卡物理链路断开掉线（Link Flap）。
本工具内置了高精度微秒级 ICMP Ping 丢包检测引擎，以 100ms 高频持续向测试主机发送 1000 字节大包，精准记录每个网口在干扰下的微秒级延迟波动、丢包次数及掉线事件。

### 2. 测试机制与分网口显示：
1. **四路网卡独立探测**：
   - 软件底层为 4 个网口分别创建独立的原始套接字（Raw ICMP Socket），并使用 Linux 内核 `SO_BINDTODEVICE` **将套接字严格绑定至对应网卡（`eth0`, `eth1`, `eth2`, `eth3`）**。
   - **按 `5` 启动后，所有已插网线（Link Up）的网口会同时以 100ms 频率独立向目标电脑发包**。
   - **未插网线（Link Down）的网口保持待命**，不会盲目发包，也不会产生虚假的丢包数据。当测试人员拔插网线或接入交换机时，网口随插即测。

2. **界面实时分网口显示**：
   每个网口都在界面上有**专属的一行实时状态**，包含：
   - 物理链路状态：`[ UP 1000M ]` 或 `[ LINK DOWN ]`
   - 静态 IP 尾号（`.101`, `.102`, `.103`, `.104`）
   - **`S:` 发包数**（Sent）
   - **`R:` 收包数**（Recv）
   - **`L:` 丢包数与丢包率**（Lost %）
   - **当前 RTT 延迟**（ms）

3. **汇总区域与最终报告**：
   - 界面 `[4-LAN Ping & Loss Monitor]` 区域实时显示四路总发包数、总收包数、总丢包数与掉线次数及当前综合评级（`CLASS A: 0-Loss PASS` / `CLASS B: <1% Transient Loss` / `CLASS C: FAIL`）。
   - 退出（按 `Q` 或 `Ctrl+C`）时，终端会打印出**包含 4 个网口各自独立成绩与整机抗扰度评级**的详细总结报告。

4. **网线热插拔自动恢复与丢包精准记录（Hotplug Auto-Recovery & Loss Logging）**：
   - **测试过程中拔下网线**：系统毫秒级感知链路断开（`carrier` 掉线），测试状态准确记录物理掉线事件（`Link Flaps++`），在断线期间，发包调度器按 100ms 周期将未通报文如实计入**已发送（Sent）与丢失（Lost）**，丢包率真实攀升至 100%，评级即时判定为 `CLASS C`。
   - **重新插上网线**：底层驱动与 PHY 完成速率自协商后，软件自动检测链路复苏（Link Up），自动复核并补全网卡静态 IP 与 Raw ICMP 套接字绑定，**零人工干预自动恢复 Ping 发包与往返延时接收**，断线期间记录的丢包数据与 Flap 掉线计数完好保留。

## 二、4 路 USB 存储设备并发读写校验压测

针对开发板上的 4 个 USB 端口（当前分别接入 `sda`, `sdb`, `sdc`, `sdd` 存储介质），软件提供全自动的并发读写稳定性测试：

1. **自动挂载与自适应文件系统**：
   - 软件自动检测并挂载到 `/mnt/rk_usb_test/{sda,sdb,sdc,sdd}`。
   - 自动适配 NTFS（通过 `ntfs-3g` 驱动）与 exFAT（通过 `exfat-fuse` 驱动），支持大容量移动硬盘与高速 U 盘。

2. **安全非破坏性测试（Non-destructive）**：
   - **绝对不破坏分区表，不影响原有用户数据**。
   - 测试通过在挂载目录下生成隐藏临时测试块（`/.rk_test_io_<dev>.dat`）进行循环读写验证。

3. **并发高强度读写与校验**：
   - 4 颗独立线程同时对 4 路 USB 设备以 1MB 数据块进行循环写入 -> `fdatasync` 强制落盘 -> 重新读取 -> 内存逐字节校验（Verify Data Integrity） -> 删除临时文件。
   - 界面实时显示：
     - **总写入/读取量（MB）**、**总写速度与读速度（MB/s）**、**错误次数（Err）** 与状态标签（`[PASS]` / `[ERR]`）。
     - **每路 USB 设备分行详情**：分两行实时显示各盘写入量、实时写速、读取量、实时读速及状态（例如 `sda: W:65M (25M) R:64M (50M) [OK]`）。
   - 退出时在终端报告中打印 4 路 USB 存储的详细盘体报告（包含设备硬件型号、介质容量、分区挂载点、测试数据量、100% 完整性校验结果与错误统计）。

4. **U盘/移动硬盘热插拔自动恢复与错误记录（Hotplug Auto-Recovery & Error Logging）**：
   - **测试过程中拔下 U 盘/移动硬盘**：
     - 读写工作线程立即捕获 I/O 中断，**精准递增硬件传输错误计数（`errors++`）及掉线事件计数（`disconnects++`）**，绝不崩溃闪退。
     - 界面即时呈现鲜红醒目的 `[DISCONNECTED (1E)]` 断连报警标识。
     - 软件后台自动执行懒卸载（`umount -l`）彻底清理 Linux 内核失效挂载节点，防止挂死或坏死锁死。
     - **测试工作线程保持驻留待命**，绝不提前退出消亡。
   - **重新插上 U 盘/移动硬盘**：
     - 驻留工作线程自动轮询探测到 `/dev/sdX` 节点重新生成。
     - 自动执行重新挂载与文件系统类型识别，自愈恢复为正常测试态（`recovers++`）。
     - **无缝恢复读写压力与内存逐字节校验测试**，历史传输量与断线产生的故障记录完全保留并如实呈现在最终退出报告中。

5. **快捷键控制**：
   - 按 **`8`**（或 `U`）随时开启 / 暂停 4 路 USB 读写压测。

## 三、RS232 与 RS485 持续单向数据传输测试

开发板板载多组 UART，硬件两两对接，软件提供高可靠性数据流测试：
1. **RS232 对接通道**：
   - **发送端**：`uart0`（设备节点 `/dev/ttyS0`）
   - **接收端**：`uart1`（设备节点 `/dev/ttyS1`）
   - **控制快捷键**：按 **`6`** 随时开启 / 暂停 RS232 传输测试。
2. **RS485 对接通道**：
   - **发送端**：`uart2`（设备节点 `/dev/ttyS2`）
   - **接收端**：`uart3`（设备节点 `/dev/ttyS3`）
   - **控制快捷键**：按 **`7`** 随时开启 / 暂停 RS485 传输测试。
3. **数据校验与实时监控机制**：
   - 波特率：`115200 8N1`，每 20ms 发送 64 字节结构化数据帧（含同步头 `0xAA55`、递增序列号、58 字节载荷及校验和）。
   - 接收端自动流式对齐帧头、严格计算校验和，并比对序列号跳变，确保无丢帧、无错码。
   - 界面单行紧凑并排显示 RS232 与 RS485 实时吞吐率与错误计数。

## 四、CAN0 与 CAN1 传输测试（支持单向与交替应答）

开发板板载两路 CAN 总线控制器（`can0` 与 `can1`，硬件已两两直连对接），软件提供高可靠性 SocketCAN 传输与数据校验压测：

### 1. 互发机制与单向传输建议
- **物理特性**：CAN 总线为单对差分线（CAN_H / CAN_L），在物理层属于**半双工仲裁总线**。若两端在毫无协议协商的情况下盲目高频并发互发，极易产生总线仲裁碰撞重传与队列拥塞。
- **为什么强烈推荐单向传输（Unidirectional）**：
  1. **故障定位极准**：通过先测试 `CAN0 -> CAN1`，再测试 `CAN1 -> CAN0`，可以精确区分并定位究竟是 CAN0 还是 CAN1 的驱动发送芯片（TX）或接收芯片（RX）存在硬件虚焊或故障。
  2. **总线零冲突**：单向传输时总线上只有一个 Master 发送方，波形纯净，无仲裁竞争抖动。
  3. **与 RS232 / RS485 保持设计一致**。

### 2. 支持的三种测试模式（随时按 `D` 切换）
1. **模式一：`CAN0 -> CAN1 (Uni)`（默认推荐）**：
   - CAN0 以 20ms 频率（50 fps）发送 8 字节标准数据帧（CAN ID `0x121`，包含同步字 `0xC0`、序列号、动态测试载荷及累加校验和）。
   - CAN1 仅负责接收并逐帧校验序列号连续性与校验和，CAN0 不收，CAN1 不发。
2. **模式二：`CAN1 -> CAN0 (Uni)`（反向单向）**：
   - CAN1 以 20ms 频率发送 8 字节数据帧（CAN ID `0x221`，同步字 `0xC1`）。
   - CAN0 负责接收并严格校验。
3. **模式三：`CAN0 <-> CAN1 (Ping-Pong)`（半双工交替应答）**：
   - CAN0 发送 Ping 请求包 -> CAN1 接收并校验后秒回 Pong 应答包 -> CAN0 接收确认完整往返。双向轮流通信，完全消除冲突。

### 3. 如何配置与控制传输方向：
- **运行中一键切换**：在主仪表盘界面随时按键盘 **`D`**，秒级切换传输方向（`0->1` ➔ `1->0` ➔ `0<->1 PP`）。
- **通过勾选菜单配置**：按 **`M`** 打开菜单，光标移到 `[9] CAN Bus Stress` 项，按 **`D`** 即可直接选择测试方向。
- **开机启动参数指定**：`sudo rk_tester --can-0to1`、`sudo rk_tester --can-1to0` 或 `sudo rk_tester --can-pingpong`。

### 4. 界面显示与退出总结：
- **实时仪表盘**：
  `CAN(0->1):   [RUN]  TX(c0):  50F/s | RX(c1):  50F/s  (0E)          [PASS]`
- **退出总结报告**：打印当前测试模式、TX 发送帧数、RX 接收校验通过帧数、丢包错误数及最终评级。

## 五、四大独立硬件功能板块与高对比度仪表盘布局

为彻底解决界面紧凑与杂乱问题，仪表盘按硬件功能域严格重构划分为 **4 个独立板块（Cards）**，每个板块顶部拥有**高对比度、鲜明醒目的彩色实体徽标标题栏（Color Badges）**，板块与板块之间加入**空行隔离带**，告别拥挤：

1. **【板块 1：计算加速与 SoC 监控】`[1..3] COMPUTE & SOC ACCELERATORS`（亮青底黑字徽标）**：
   - 整合 CPU 8 核满载压测、Mali-G52 GPU 离屏渲染压测、RK-NPU 双核 6 TOPS 推理压测。
   - 实时监控板载内存使用率（RAM Load）与 4 组关键温度传感器（SoC、大核 BigCore、GPU、NPU）。
2. **【板块 2：四路千兆以太网与 EMC 监测】`[5] 4-PORT GIGABIT ETHERNET`（翠绿底黑字徽标）**：
   - 整合 4 路独立网口（eth0 ~ eth3）物理链路载波状态（Link UP/DOWN）、协商速率与 IP 尾号。
   - 整合 100ms 高频 ICMP Ping 丢包监测、各网口独立丢包统计与延迟、EMC 综合抗扰度评级（CLASS A/B/C）及网络事件流水。
3. **【板块 3：工业现场总线测试】`[6,7,9] INDUSTRIAL FIELDBUS`（明黄底黑字徽标）**：
   - 整合 RS232 两两对接单向流传输（ttyS0 -> ttyS1）、RS485 两两对接单向流传输（ttyS2 -> ttyS3）。
   - 整合 CAN0/CAN1 现场总线压测，支持按 `D` 随时切换单向与 Ping-Pong 交替传输。
4. **【板块 4：高速 USB 存储读写压测】`[8] 4-PORT USB STORAGE`（深蓝底白字徽标）**：
   - 整合 4 路 USB 存储设备并发读写压力测试。
   - 汇总显示总吞吐率与校验结果，并分行详细列出每块介质（sda、sdb、sdc、sdd）的读写量、读写速度与健康状态。
5. **动态终端自适应（Adaptive Resizing）**：
   - **紧凑模式（标准 80x24 终端）**：各板块以高度规整的 24 行严格排布，各板块间均保留清晰的空行分隔带，所有信息不滚动、无溢出、无重叠。
   - **宽屏舒适模式（终端高度 >= 30 行）**：CPU 8 核展开为 4 行独立动态条形图，以太网展开事件流水行，板块间距进一步舒展。

## 六、如果测试电脑使用别的 IP 怎么办？

**完全不用担心！软件已内置「智能网段自动自适应」功能：**

1. **同网段换 IP（如电脑是 `192.168.32.88`）**：
   - 方式 A：启动时直接输入：`sudo rk_tester 192.168.32.88`
   - 方式 B：软件运行中随时按键盘 **`T`**，输入新 IP 并回车，立即无缝切换！

2. **跨网段换 IP（如电脑是 `192.168.1.50`、`10.0.0.88` 等完全不同的网段）**：
   - **全自动自适应**：只要您指定了新网段的目标 IP（通过启动参数或按 `T`），**`rk_tester` 会全自动为 4 路网卡配置该网段的对应子网 IP（如 `192.168.1.101 ~ 104`）**！
   - 开发板原有的 `192.168.32.101` 管理 IP 与 SSH 仍会安全保留不受任何影响。
   - 无论测试电脑处于什么网段，开发板网口都会秒级自动匹配电脑网段并立即互通！

## 七、目标测试电脑需要做什么？

**这台电脑不需要运行任何额外的测试软件！**

- **原理**：测试使用的是网络层 ICMP Echo 协议（标准 ping），操作系统内核自带自动应答。
- **配置要求**：
  1. 将电脑 IP 设置为 `192.168.32.100`（或在板端按 `T` 键指定的目标 IP），子网掩码 `255.255.255.0`。
  2. 确保防火墙放行 Ping（Windows 电脑请启用「文件和打印机共享(回显请求 - ICMPv4-In)」或测试期间临时关闭防火墙）。
  3. 用网线直连被测网口，或将被测网口与电脑同时插在千兆测试交换机上。

| **`6`** | **【手动开始 / 暂停】RS232 串口持续单向数据传输测试（ttyS0 -> ttyS1）** |
| **`7`** | **【手动开始 / 暂停】RS485 串口持续单向数据传输测试（ttyS2 -> ttyS3）** |
| **`8`** | **【手动开始 / 暂停】4-Port USB 存储读写压测（sda..sdd 并发读写与校验）** |
| **`9`** | **【手动开始 / 暂停】CAN 总线传输测试（默认单向 500kbps 8B数据帧）** |
| **`D`** | **【切换 CAN 传输方向】循环切换 `CAN0->1 (单向)` / `CAN1->0 (单向)` / `CAN0<->1 (交替应答)`** |
| **`T`** | **修改测试目标电脑 IP**（交互式输入新的电脑 IP，如 `192.168.32.88`，回车立即生效） |
| **`R`** | **清零重置所有统计计数**（网口统计、串口统计、USB 读写统计、CAN 统计全部归零） |
| **`P`** | **切换调频策略**（在【性能 PERFORMANCE】与【动态节能 SCHEDUTIL】之间切换） |
| **`I`** | **重新初始化四路网卡 IP** |
| **`Q`** | **退出软件**（自动关闭所有测试与压测，并在终端打印全套测试总结报告） |
